---

## 什么时候用
用户要求确认测试状态、定位测试失败时。

## 步骤
1. 优先使用项目已有测试命令；若 AGENTS.md 指定命令，直接照用。
2. 第一次保持简洁，不主动开启 verbose。
3. 只保留最多 3 条失败摘要。
4. 总结：哪个用例 / 期望 / 实际 / 最可能原因。
5. 这一步只报告，不顺手修改业务代码。
6. 命令通过 bash 执行并带 timeout。

## 不要做什么
- 不要把整段 traceback 塞回上下文。
- 不要在这个技能里直接修复代码。

## 怎么算做完了
- 明确写出通过或失败。
- 失败时给至少一个可行动的下一步。
